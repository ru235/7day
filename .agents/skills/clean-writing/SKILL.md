# Чистое письмо без нейро-слопа

Пиши как опытный редактор, который ненавидит шаблоны нейросетей. Текст должен быть точным, коротким, по-деловому, без воды.

## Что такое нейро-слоп

Набор маркеров, по которым палится AI-текст:

**Лексика:** раскрывает потенциал, погрузитесь, откройте для себя, в современном мире, идеальное решение, уникальный, инновационный, эффективный, оптимизируйте, трансформируйте, поднимите на новый уровень, независимо от того, будь то, в конечном счёте, в заключение, важно отметить.

**Синтаксис:** сплошные тире — в каждом предложении, длинные сложносочинённые на 3 строки, одинаковые начала абзацев, списки из 3 пунктов с одинаковой длиной, навязчивые вопросы к читателю.

**Тон:** приторный восторг, пустые обещания, отсутствие конкретики, общие фразы вместо цифр/фактов, пафос вместо пользы.

**Структура:** Hero с eyebrow + H1 + водянистый абзац на 4 строки, затем 3 карточки с иконками, затем FAQ с общими ответами.

## Правила чистого текста (чек-лист)

- Факты > прилагательные. Цифры, размеры, марки, ГОСТ, допуски, цены, сроки.
- Коротко: 1 мысль = 1 предложение 12–18 слов. Абзац 2–3 предложения.
- Глагол в начале: посчитайте, введите, возьмите, проверьте — а не «вы сможете осуществить расчёт».
- Без тире-спама: 1 тире на 2–3 предложения, не в каждом. Используй точку, двоеточие, скобки.
- Без канцелярита: не «осуществить подбор», а «подобрать»; не «данный материал», а «фанера».
- Без generic-CTA: не «Начните прямо сейчас», а «Рассчитать — 30 сек».
- Конкретика для инженера: допуск ±3%, рез 0.15 мм, шаг 35 мм, BCT по Макки, лист 1525×1525.
- Русский — живой разговорный, но точный. Английский — прямой, без buzzwords.
- FAQ — вопрос как у клиента, ответ 1–2 предложения с действием.

## Как проверять сайт

1. Пройди все страницы, выпиши Hero H1, описание, TL;DR, карточки, FAQ, плейсхолдеры.
2. Отметь маркеры слопа: тире, штампы, вода, повторы.
3. Оцени по шкале: 0 — чисто, 1 — лёгкий налёт, 2 — явный слоп.
4. Перепиши каждый блок по правилам выше, сохранив смысл и SEO-ключи, но убрав шаблоны.

## Как переписывать

- Сохрани ключи (FEFCO 0201, гофрокартон, BCT) и факты (размеры, формулы).
- Замени слоп-фразы на действие + цифру.
- Разбей длинные абзацы, убери вводные «важно отметить».
- Проверь после: прочитай вслух — звучит как человек у станка / на складе?

## Примеры

**Слоп:** «Откройте для себя инновационное решение для упаковки, которое раскроет потенциал вашего бизнеса и оптимизирует логистику в современном мире — быстро, эффективно и надёжно.»

**Чисто:** «Коробка 0201: заготовка 1030×350 мм для 300×200×150, клапан 30 мм. Считает за секунды.»

**Слоп FAQ:** «В: Какие преимущества даёт использование нашего калькулятора? О: Наш калькулятор предоставляет широкие возможности для оптимизации...»

**Чисто FAQ:** «В: Как посчитать 0201? О: Введите L×W×H — получите заготовку с клапаном.»
