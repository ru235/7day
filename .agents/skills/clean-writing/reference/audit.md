# Аудит на нейро-слоп

## Чек-лист для каждой страницы

Пройди страницу и отметь:

- [ ] H1: содержит ли штамп "Откройте", "Идеальное решение", "В современном мире", "Уникальный"?
- [ ] Описание под H1: вода >30% (общие фразы без цифр)? Длина >25 слов?
- [ ] TL;DR: есть ли тире в каждом предложении? (подсчитай — 1 на 3 предложения норма)
- [ ] FAQ: ответы общие без цифр/действий? Начинаются с "Наш калькулятор предоставляет..."?
- [ ] Тон: приторный восторг (восклицания, "превосходный", "невероятный")?
- [ ] Повторы: одинаковые начала абзацев, списки 3× одинаковой длины?
- [ ] Тире-спам: >8 тире на 500 знаков?

## Шкала

- 0 — чисто: факты, цифры, глаголы, 1 тире на 3 предложения
- 1 — налёт: 2–3 штампа, можно подчистить
- 2 — слоп: >5 штампов, переписать блок

## Что выписать

Для каждой страницы (/, /fefco/, /gofro/, /prochnost/, /primery/) — H1, описание, TL;DR, 3 карточки, FAQ (по 1 вопросу). Оцени каждый блок 0/1/2.
