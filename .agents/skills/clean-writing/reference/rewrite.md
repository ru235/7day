# Приёмы переписывания без слопа

## Замены

- "Откройте для себя инновационное решение" → "Коробка 0201: заготовка 1030×350"
- "В современном мире логистики" → убрать
- "Идеально подходит для любых задач" → "Для переезда, маркетплейсов, архива — разные типы"
- "Наш калькулятор предоставляет возможность" → "Введите L×W×H — получите заготовку"
- "Важно отметить, что" → убрать
- " — " в каждом предложении → заменить на точку или двоеточие

## Структура

- Hero: H1 4–5 слов + 1 предложение 12–15 слов с цифрами
- Описание: 1 предложение с фактом (профили, марки, BCT)
- TL;DR: 2 предложения, глаголы, без тире-спама
- Карточки: заголовок 2 слова, описание 8–10 слов с пользой
- FAQ: вопрос как у клиента (5–7 слов), ответ 1–2 предложения с действием + цифрой

## Проверка после

Прочитай вслух. Звучит как мастер на складе? Да → готово. Нет → упрости ещё.
